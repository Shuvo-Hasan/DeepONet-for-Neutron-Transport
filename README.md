# DeepONet-for-Neutron-Transport
Deep Operator Networks (DeepONet) is a neural network architecture designed to learn mapping between functions. https://arxiv.org/abs/1910.03193

Here, it has been applied to solve the Boltzmann Transport Equation for neutron transport in nuclear reactors. The idea is to build a surrogate model for neutron transport that will lead the way for digital twins of nuclear reactors.
